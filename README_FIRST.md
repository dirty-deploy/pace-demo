# Pace demo build kit

Open Claude Code in this folder and paste the contents of `PROMPT.txt`.

| File | What it is |
|---|---|
| `BUILD_SPEC.md` | Full build spec (screens, formulas, design rules, definition of done) |
| `PROMPT.txt` | The starting prompt to paste |
| `DESIGN.md` | Visual direction: palette, type, buttons, each screen's layout, anti-slop checklist |
| `reference/inspiration/` | 8 reference sheets (frames from UI recordings) plus a README on what to borrow |
| `data/sample_sets.json` | 15 original, solver-verified seating puzzles (5 Easier, 5 Medium, 5 Harder) |
| `data/demo_student.json` | Fictional student profile, sessions, pace history, sample replay |
| `reference/user_journey_flow.png` | Our own diagram of the student journey |
| `reference/set_pipeline_flow.png` | Our own diagram of the generator → solver → difficulty pipeline |
